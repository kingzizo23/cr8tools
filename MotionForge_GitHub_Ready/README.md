# MotionForge 🚀

Client-Side Motion Graphics Studio — Inspect, preview, edit, compress, and convert SVGA, Lottie, VAP, YYEVA, Dual-Channel MP4, WebP, APNG, GIF & PNG Sequences entirely inside your browser.

- **100% Client-Side:** Zero backend processing, 100% privacy, zero server costs.
- **100% Free & Unlimited:** No auth, no PRO paywalls, no daily quotas.
- **Bilingual:** Full Arabic (RTL) & English (LTR) support.

## 🛠️ Deploy to Vercel

1. Push this repository to GitHub.
2. Go to [Vercel Dashboard](https://vercel.com).
3. Click **Add New Project** and select your GitHub repository.
4. Framework Preset will auto-detect as **Vite**.
5. Click **Deploy**.

> Note: `vercel.json` is already configured with the required `Cross-Origin-Opener-Policy` and `Cross-Origin-Embedder-Policy` headers for WebAssembly multi-threading.

## 💻 Local Development

```bash
npm install
npm run dev
```

Build production bundle:
```bash
npm run build
```
